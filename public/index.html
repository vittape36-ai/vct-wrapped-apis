06 // FAQS

System Inquiries

Exploring structural inquiries and deployment operations.

How does the failover gateway model behave?

We monitor timeouts and rate exceptions inline (like HTTP 429 and 500s). If an active provider fails to respond within set bounds, VCT immediately diverts requests to standby provider pools (e.g. switching from OpenAI to Gemini) in under 12ms.

Is there a latency cost for wrapping requests?

No. Our gateway is running on optimized V8 edge routines adding less than 1.2ms of overhead. With Redis Edge Caching enabled, repeated queries bypass upstream compilation entirely, serving requests in under 5ms.

How does key cooldown protect credentials?

API keys rotate inside an active queue. When an upstream key hits a rate restriction (HTTP 429), it is tagged with a cooling interval and shifted to the back of the queue. Subsequent calls run immediately on fresh credentials.
